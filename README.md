# BeautyBook — онлайн-запис до майстрів краси

**BeautyBook** — навчальний вебзастосунок для пошуку майстрів краси та онлайн-запису на послуги.

Проєкт розробляється в межах курсу з кросплатформного програмування.

## Можливості застосунку

- Перегляд каталогу майстрів краси.
- Пошук майстрів за ім'ям, спеціальністю та назвою послуги.
- Фільтрація майстрів за містом і спеціальністю.
- Сортування майстрів за ім'ям і вартістю послуг.
- Перегляд профілю майстра, опису та переліку послуг.
- Реєстрація та авторизація користувачів.
- Онлайн-запис до майстра на вибрану послугу.
- Перегляд власних записів.
- Скасування майбутніх записів.
- Перевірка доступності часу та запобігання записам, що перетинаються.

## Використані технології

- **C#**
- **.NET 8**
- **ASP.NET Core MVC**
- **Entity Framework Core 8**
- **SQLite**
- **ASP.NET Core Identity**
- **Razor Views**
- **xUnit**
- **Git та GitHub**

## Структура проєкту

- `Controllers/` — контролери вебзастосунку.
- `Models/` — моделі даних.
- `Views/` — сторінки інтерфейсу.
- `Data/` — контекст бази даних та її початкове наповнення.
- `Migrations/` — міграції Entity Framework Core.
- `tests/BeautyBook.Tests/` — автоматичні тести.
- `wwwroot/` — статичні файли.

## Як запустити проєкт

**Необхідно:** встановити .NET 8 SDK.

1. Клонувати репозиторій:

   ```bash
   git clone https://github.com/kornienkosvitlana20/BeautyBook.git
   ```

2. Перейти до папки проєкту:

   ```bash
   cd BeautyBook
   ```

3. Відновити залежності:

   ```bash
   dotnet restore
   ```

4. Запустити застосунок:

   ```bash
   dotnet run
   ```

5. Відкрити в браузері адресу, яку покаже термінал.

Під час першого запуску застосунок створює базу SQLite, застосовує міграції та додає початкові дані для демонстрації.

## Тестування

Для запуску автоматичних тестів:

```bash
dotnet test
```

На поточному етапі успішно пройдено **10 автоматичних тестів**.

Тести перевіряють правила роботи з часовими інтервалами та коректність часу запису.

## Робота з Git

Розробка ведеться в окремих гілках:

- `feature/poshuk-maystriv` — каталог, пошук і профілі майстрів, моделі даних, міграції та тести.
- `feature/onlain-zapys` — функціональність онлайн-запису (окрема гілка розробки).
